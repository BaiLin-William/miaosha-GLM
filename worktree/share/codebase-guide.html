Chrome MV3 Browser Extension

智谱 Coding Plan 秒杀助手

一个系统性辅助抢购 bigmodel.cn 限量套餐的 Chrome 扩展。通过验证码预取、NTP 校时、 同源请求代理与自动并发开火，在秒杀瞬间以页面 origin 发起下单请求。

框架 WXT 0.20.26 UI Svelte 5 测试 Vitest 4 + Playwright 语言 TypeScript 状态 积极开发

核心功能

R1–R4 + DEV/PROD
  • R1 倒计时提醒：系统通知 + 角标倒计时（60/30/15/5 分钟前）
  • R2 验证码预取：拦截 Tencent CAPTCHA ticket，缓存 ticket 池
  • R3 页面内提醒：bigmodel.cn 标签页顶部横幅 + 蜂鸣提示
  • R4 角标倒计时：扩展图标 Badge 动态显示剩余时间
  • DEV 模式：Popup 内直接调用 7 个 bigmodel API 端点
  • PROD 模式：一键跳转 bigmodel.cn，配合页面覆盖层完成秒杀
  • 自动开火：基于服务器时间校准，在秒杀瞬间自动并发请求
  • 开火可视化：3×3 产品矩阵实时展示每发请求状态

核心数据流

6 条关键链路

🔐 Auth 获取链路

1popup 打开 / content script 启动
2chrome.scripting.executeScript → MAIN world
3读取 cookie + localStorage
4写入 local:authHeaders

🎫 Ticket 预取链路

1用户通过 Tencent CAPTCHA
2bm-main XHR 拦截 ticket
3postMessage → bm-capture
4写入 local:ticketPool（TTL 5min）

🛒 秒杀开火链路

1用户点击 FIRE / 自动触发
2bm-capture 读取 ticket + auth
3同源 fetch /api/biz/pay/preview
4成功后写入 local:paymentState

⏰ 提醒调度链路

1options 保存 saleTimeConfig
2background 计算下次秒杀时间
3chrome.alarms 注册提醒点
4触发 notifications + badge

🎯 产品矩阵链路

1batch-preview API 返回 9 产品
2buildProductMatrix 分组 3×3
3覆盖层渲染可选产品卡片
4选择状态同步到 storage

🕐 NTP 校时链路

1probe batch-preview 8 次
2取最佳 60% RTT 中位数
3计算 clockOffsetMs + latencyMs
4自动开火按服务器时间触发
